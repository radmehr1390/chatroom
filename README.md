# موج — شاخهٔ سخت‌سازی v9

موج یک پیام‌رسان وب فارسی با رابط RTL و بک‌اند PHP/MySQL است.

> این شاخه برای بررسی و آماده‌سازی امنیتی است. نسخهٔ نهایی تولیدی نیست و امتیاز امنیتی تضمین‌شده ندارد.

## تغییرات این شاخه

- حذف اسکریپت عمومی پاک‌سازی کامل دیتابیس.
- حذف log حاوی مسیرها و خطاهای داخلی از مخزن.
- حذف اسکریپت مهاجرت قابل اجرا از مرورگر.
- حذف مقادیر پیش‌فرض حساس از `config.php` و غیرفعال‌کردن نمایش خطا به بازدیدکننده.
- افزودن headerهای امنیتی پایه و منع دسترسی مستقیم به فایل‌های پیکربندی، log و dumpهای SQL.
- افزودن `.gitignore`, `.env.example` و `SECURITY.md`.

## راه‌اندازی امن

1. ابتدا روی یک محیط آزمایشی با نسخهٔ PHP سازگار اجرا کنید.
2. از دیتابیس و فایل‌های کاربر نسخهٔ پشتیبان بگیرید.
3. متغیرهای محیطی مطابق `.env.example` را در تنظیمات اجرای PHP تنظیم کنید.
4. کلید SMS.ir و رمز دیتابیس قدیمی را که قبلاً در مخزن بوده‌اند تعویض کنید؛ مقادیر قبلی را امن فرض نکنید.
5. پوشهٔ log خصوصی را بیرون از ریشهٔ عمومی بسازید و دسترسی آن را محدود کنید.
6. مهاجرت‌های لازم را ابتدا روی یک کپی از دیتابیس اجرا و صحت schema را با نسخهٔ برنامه تطبیق دهید.
7. تست ورود/OTP، ارسال پیام، آپلود، نشست‌ها، logout، دسترسی گفتگو و بازیابی backup را اجرا کنید.
8. تنها پس از موفقیت تست‌ها، نسخه را با برنامهٔ rollback منتشر کنید.

## مهم

- تنظیم نکردن متغیرهای دیتابیس در این شاخه باعث خطای پیکربندی می‌شود؛ این رفتار عمدی است تا برنامه به رمز پیش‌فرض و ناامن متکی نباشد.
- این commitها به‌تنهایی تاریخچهٔ Git را از secrets قدیمی پاک نمی‌کنند. پس از تعویض کلیدها، تاریخچه را جداگانه پاک‌سازی کنید.
- این شاخه هنوز پیاده‌سازی کامل E2EE یا تأیید امنیتی مستقل را ادعا نمی‌کند.
- جزئیات اقدامات فوری و چک‌لیست انتشار در `SECURITY.md` آمده است.
